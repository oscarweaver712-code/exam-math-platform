# Оставшиеся требования проекта «Школа 911»

**Дата сверки:** 16 августа 2026 года.

## Границы сверки

Проверена доступная в этой задаче история пользовательских комментариев, а также проектные материалы: `todo.md`, `audit_review.md`, `bank-stabilization-roadmap.md` и `russia_launch_policy.md`. Внешние чаты, не переданные в контекст проекта, недоступны для автоматического просмотра; если в них есть дополнительные решения владельца, их следует прислать сюда или добавить в проектные заметки.

## Уже закрыто по доступной истории

Публичный банк защищён постраничной выдачей; редакционная очередь также ограничена страницами. У задач устранено публичное поле сложности, а для новых материалов требуются год ОГЭ и источник. Добавлена первая проверенная партия тренировочных адаптаций 2023–2026, фильтр по году, назначение редакторов, роли кабинета, настройки отдельным разделом, отзыв административного доступа владельцем и верхний Telegram-баннер.

Мобильная навигация кабинета теперь использует компактную кнопку «Разделы кабинета» и выезжающую слева панель с затемнением фона, закрытием по `Esc`, клику по фону, кнопке закрытия и после выбора раздела. Desktop сохраняет постоянное левое меню.

## Открытые работы, упорядоченные по приоритету

| Приоритет | Требование | Текущее состояние | Следующий практический шаг |
|---|---|---|---|
| Высокий | Массовое наполнение банка только проверенными материалами ОГЭ 2023–2026 | Загружена первая небольшая партия; процесс проверки и источники есть | Пополнять банк редакционно подтверждёнными адаптациями, включая схемы и alt-текст там, где они нужны |
| Высокий | Неизменяемый внутренний ID задачи | В модели и интерфейсе требование пока не закрыто в долгосрочном backlog | Ввести системный ID, показывать его редакторам, поддержать фильтрацию и журнал аудита |
| Высокий | Правило обязательных визуалов по каждому номеру КИМ | Есть очередь модерации медиа, но нет полного справочника требований | Добавить в справочник КИМ признаки обязательной схемы, подсказки и publish-gate |
| Средний | Автоматическая ежемесячная подготовка вариантов ОГЭ | Варианты вручную генерируются, планировщик пока не включён | Добавить идемпотентную ежемесячную задачу, документацию активации и контроль владельца |
| Средний | Тестовое покрытие вариативного и редакционного контура | Базовые 19 тестов проходят, но backlog фиксирует недостающие сценарии | Добавить Vitest-проверки правовой блокировки импорта, модерации изображений, состава КИМ, вариантов и планировщика |
| Средний | Полная UX-приёмка публичного банка и варианта | Кабинет и drawer проверены; общий маршрут банка/вариантов требует отдельной приёмки | Проверить desktop/mobile путь «каталог → задача → вариант → ответ» и сохранить контрольную версию |
| Средний | Роут для ЕГЭ | В backlog остаётся явный placeholder | Добавить безопасную страницу «ЕГЭ — скоро» с маршрутизацией, без имитации готового контента |
| Обязательное условие запуска | Юридическая проверка РФ | Технические ограничения и политика есть, но это не юридическое заключение | Перед массовой публикацией согласовать персональные данные, пользовательские документы, права на материалы и возрастные сценарии с профильным юристом |

## Что не следует добавлять в ближайший релиз

В доступной стратегии проекта намеренно отложены встроенный чат, видеохранилище, платежи, бухгалтерия и ИИ-проверка развёрнутой части. Сначала следует довести до реального использования связку «проверенный банк → назначение → ответ → проверенный результат → прогресс».
