# Immutable ID заданий

## Решение

Поле `tasks.internalId` является **неизменяемым редакционным идентификатором**. Оно уже было определено в схеме как обязательное и уникальное, поэтому новая колонка и рискованная миграция не требуются. Аудит рабочей базы подтвердил, что у всех **86** существующих записей значение заполнено и уникально.

Новые записи, созданные через редактор или при конвертации правомерно зарегистрированного внешнего материала, получают идентификатор на сервере в формате `SH911-OGE-<случайный_код>`. Этот ID не передаётся редактором во входных данных и не входит в `updateTask`; изменение условия, решения, статуса или метаданных не меняет ID.

## Правила для редакции

| Действие | Правило |
|---|---|
| Создание задачи | Сервер назначает immutable ID автоматически. |
| Редактирование | ID отображается только для чтения и сохраняется прежним. |
| Поиск в очереди | Используйте поле «Поиск по immutable ID». |
| Архивация или мягкое удаление | ID остаётся связанным с историей и редакционными событиями. |
| Внешние материалы | Их ID не заменяет проверку прав и не разрешает копирование содержания. |

## Проверка

Интеграционный тест создаёт задачу, проверяет server-generated ID, находит её по ID, обновляет содержание и подтверждает неизменность идентификатора. Отдельно проверяется авторская задача без внешнего URL.
