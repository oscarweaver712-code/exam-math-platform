# Варианты, импорт и маршрутизация — проектное решение

**Статус:** согласовано с владельцем 15 августа 2026 года.

## Зафиксированные правила

| Решение | Правило продукта |
| --- | --- |
| Ежемесячный вариант | Система создаёт и **сразу публикует** вариант по расписанию. Генерация идемпотентна: один выпуск на трек и календарный месяц. |
| Состав ОГЭ | Полный вариант содержит **25 позиций**: КИМ №1–19 относятся к Части 1, №20–25 — к Части 2. Это соответствует официальной спецификации ОГЭ по математике 2026 года. [1] |
| Пользовательский вариант | Генерируется только для текущей браузерной сессии, не сохраняется в личный кабинет и не влияет на учебную аналитику. |
| ЕГЭ | Маршрут выбора создаётся сейчас, но пустой трек явно сообщает о готовящемся наполнении и не имитирует несуществующий банк. |
| Внешний контент | Любая внешняя задача проходит ручную карточку импорта и обязательное решение о правовом основании **до** создания редактируемого черновика задачи. |
| Внешние изображения | Внешние изображения поступают в изолированную очередь модерации; в публичную задачу попадают только после отдельного одобрения. |

## Новые сущности

| Сущность | Назначение | Ключевые статусы/инварианты |
| --- | --- | --- |
| `content_import_cases` | Карточка ручного импорта внешней задачи | `rights_review → cleared/rejected → converted`; конвертация в задачу невозможна до `cleared`. |
| `content_import_events` | Неизменяемый журнал решений по импорту | Кто, когда и на каком основании изменил правовой статус. |
| `task_visuals` (расширение) | Уже существующий визуальный материал | Для внешнего изображения фиксируются модератор, дата и мотив решения; публичная выдача допускает только `approved`. |
| `exam_variants` | Опубликованный ежемесячный вариант | Уникальный ключ выпуска `track + monthKey`; автоматическое создание не дублирует уже выпущенный вариант. |
| `exam_variant_items` | Зафиксированный список задач варианта | Хранит задачу, версию её содержимого и порядок №1–25. |
| `variant_generation_schedules` | Конфигурация фоновой ежемесячной генерации | Хранит идентификатор задания расписания и последнее обработанное окно. |

## Маршрутизация

Публичный путь строится без привязки к одному предмету:

```text
/ → /subjects → /subjects/:subjectSlug → /subjects/:subjectSlug/:trackSlug
                                              ├─ /bank
                                              ├─ /variants
                                              └─ /variant/session  (только текущая сессия)
/variants/:variantSlug  (опубликованный вариант)
```

Старые ссылки `/bank` и `/bank/:slug` сохраняются как совместимые входы в активный трек «Математика → ОГЭ».

## Алгоритм формирования варианта

1. Для каждого номера КИМ №1–25 выбирается одна опубликованная авторская задача соответствующего типа.
2. Генератор исключает архивные, мягко удалённые и неавторские записи; тем самым месячный вариант не зависит от внешнего контента с неуточнёнными условиями использования.
3. Если по какому-либо номеру нет допустимой задачи, вариант не публикуется, а администратор получает понятную диагностическую запись.
4. Для повторяемости месячный выбор использует детерминированный ключ `examTrack + YYYY-MM + kimNumber`; пользовательская сессия выбирает из того же разрешённого пула без записи в базу.

## Автоматический запуск

Ежемесячный запуск — детерминированная серверная задача с HTTP-обработчиком. Он запускается платформой по расписанию, проверяет собственный идентификатор задания, создаёт недостающий выпуск и возвращает JSON-результат. Обработчик не использует таймеры процесса и сохраняет идемпотентность при повторном вызове. Настройка реального запуска выполняется только после публикации сайта.
